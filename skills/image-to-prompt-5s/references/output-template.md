# 输出模板

以下方结构为默认格式；根据图片复杂度调整长度，避免填充无关字段。

## 参考图拆解

0. **任务目标**：用途（用户指定 / 推断）；视觉重点。
1. **Subject 主体**：数量、外观、动作、关系；文案及角色。
2. **Style 风格**：媒介、配色、材质与气质。
3. **Shot 镜头与构图**：视角、位置、比例、景深、留白、文字布局。
4. **Setting 场景与环境**：背景、空间、辅助元素。
5. **Scene lighting 光照与影调**：方向、软硬、冷暖、明暗关系。
6. **约束条件**：保留项；替换项；避免项；有冲突时的优先级。

在对应条目内标注推断即可，不必为每个可见事实重复“观察到”。

## 可直接使用的提示词

用一个代码块写成自然语言成稿。以下仅为编写顺序，交付时替换为实际内容并去掉占位说明：

```text
生成一张【用途与画幅】。画面主体为【主体数量、外观、动作、相互关系】。
采用【媒介、色彩、材质与气质】。使用【视角、主体位置与占比、层次、留白】。
背景为【环境及辅助元素】。光线呈现【方向、软硬、色温与明暗关系】。
画内文案为“【需要的精确原文】”，【出现次数、位置、字体类别、层级和对齐】。
保留【关键特征】；替换【用户指定的改动】；避免【与当前画面有关的错误】。
如有实际冲突，优先保证【已明确的优先级】。
```

没有文字或替换任务时删除相应句子。有参考图输入时额外写清“图 1 用于……，图 2 用于……”。只要纯提示词时不输出本页其他部分。
