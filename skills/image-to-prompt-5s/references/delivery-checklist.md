# 交付检查

在输出成稿前检查一次，不必把清单重复给用户。

- 数量与关系：没有漏掉第二个人、增加道具或颠倒左右位置。
- 构图与留白：画幅方向、主体占比、标题区域与用户用途相容；比例估算不冒充测量结果。
- 光照与媒介：平面色块没有被强加摄影光影；环境、阴影和反射不矛盾。
- 文字：原文、次数、断行、对齐均明确；英文提示词没有翻译应保留的中文；模糊文案未被猜写。
- 模式：忠实还原不擅自美化；替换任务明确改动与保留项；多图各司其职。
- 可执行性：没有“同上”“跟原图一样”等唯一描述，没有遗留占位符、未决选项或跨工具参数。
- 证据：推断在拆解中标明；成稿不把相机、身份或不可见结构写成已知事实；不声称找回原始 prompt。

对局部修改的成稿，写出改动对象与保留项，并提示在生成时附上参考图；该提示放在代码块外，用户只要 prompt 时可直接把参考角色写入成稿。
